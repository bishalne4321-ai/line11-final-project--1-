# Line 11 — Study Subway

Chapter 11 final project: a responsive landing page built with HTML, CSS, and JavaScript, published with GitHub Pages.

The page is designed like a Seoul subway line. The three study habits — **Plan (계획)**, **Focus (집중)**, and **Review (복습)** — are the stations.

## Live site

https://YOUR-USERNAME.github.io/line11/

## Folder structure

```text
line11/
├── index.html
├── styles.css
├── script.js
├── README.md
└── images/
    └── hero.svg
```

- **index.html** — header, hero, features, footer, and popup markup
- **styles.css** — desktop + mobile layout and popup styles
- **script.js** — open / close popup, including Escape and overlay click
- **images/hero.svg** — Line 11 route map

## What the page includes

- Header with logo and navigation (Home, Features, About)
- Hero section with a two-column grid layout
- Three feature cards connected by a subway line
- Footer with a "Back to top" link
- About popup that closes with the ✕ button, an overlay click, or the Escape key
- Responsive layout that stacks into one column at 760px and below

## Deploy

```bash
git add .
git commit -m "Complete Line 11 project"
git push
```

Then on GitHub: **Settings → Pages → Deploy from a branch → main / (root) → Save**.
